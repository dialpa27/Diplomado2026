Boostrap

Bootstrap es un framework o marco de trabajo que combina CSS, HTML y JavaScript. Su objetivo principal es ayudar a los desarrolladores a crear sitios web que se vean bien y funcionen en cualquier dispositivo (movil, tableta o PC) de forma extremadamente rapida, Es como una biblioteca llena de herramientas listas para usar que evita tener que escribir milies de lineas de CSS desde cero.

Divide la pantalla en 12 columnas invisibles. Esto permite decidir cuanto espacio ocupa cada elemento del sitio web dependiendo del dispositivo. Incluye clases ya listas para:

  1. Botones con colores y efectos.
  2. Barras de navegacion (navbars) que se colapsan en moviles
  3. Ventanas Modales (Ventanas emergentes).
  4. Carruseles de imagenes.
  5. Formularios estilizados.

Columnas1

La Clase container sirve para que el contenido se mantenga en una columna central organizada y que asi el contenido no llegue hasta los bordes. La clase row sirve para crear filas. La clase col sire para crear columnas. Todo el contenido dem i web debe ir dentro de columnas que a su vez estan entro de filas que a su vez estan dentro de un contenedor
