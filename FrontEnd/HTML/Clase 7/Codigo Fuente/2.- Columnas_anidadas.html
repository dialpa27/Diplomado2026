Clase col-12

La clase col-12 es una de las piezas mas importantes del sistema de rejilla de Bootstrap. Bootstrap divide horizontalmente la pantalla en 12 columnas imaginarias.

  1. col: Indica que el elemento se comportara como una columna
  2. 12: Indica cuantas de esas 12 columnas disponibles deben ocupar el elemento.

Al usarla se le dice al navegador que la columna ocupara todo el ancho disponible.



Clase col-md-6

La clase col-md-6 es una instruccion especifica que le dice al navegador como debe comportarse un elemento cuando la pantalla alcanza un tamaño determinado.

  1. col : Indica que el elemento se comportara como una columna.
  2. md: Se refiere a pantallas "Medium" (medianas), como tablets o laptops pequeñas (desde los 768px de ancho en adelante).
  3. 6: Es el numero de Columnas que ocupa. (1/2 de la pantalla)

    4. Al usarla se le dice al navegador que la columna ocupara todo el ancho disponible.
